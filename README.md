# 🧠 Hekto Admin Dashboard (Authentication + CMS Control Panel)

A secure and scalable **admin dashboard system** built as part of the Hekto E-Commerce Furniture Platform during a highly competitive hackathon with **500+ participants**.

This dashboard extends the main e-commerce system into a **full-stack production-level ecosystem** with authentication, CMS integration, and admin-level product management.

---

## 🚀 Live Demo
👉 https://dashboard-eta-seven-72.vercel.app/

---

## 📌 Overview

The Hekto Admin Dashboard is a powerful control panel designed for managing the entire e-commerce platform.

It allows authenticated admin users to:

- Manage products dynamically
- Control CMS-based content (Sanity)
- Handle secure admin access
- Maintain scalable e-commerce data flow

This project represents a major step in my journey from frontend development to **full-stack system design thinking**.

---

## 🎯 Problem Statement

Most e-commerce applications focus only on the customer-facing store and ignore the need for a real-world admin system.

Without an admin dashboard:

- Product updates become manual and inefficient
- Content management is not scalable
- Security and role-based access are missing

---

## 💡 Solution

I built a **secure admin dashboard system** with authentication and CMS integration that enables:

- Centralized product management
- Secure admin-only access
- Dynamic content updates via Sanity CMS
- Scalable architecture for real-world usage

---

## ✨ Key Features

- 🔐 Authentication system (secure admin access)

- 🔄 Dynamic content control
- 🧩 Modular architecture

---

## 🧱 Architecture

- **Frontend:** Next.js (App Router)
- **CMS:** Sanity Headless CMS
- **Styling:** Tailwind CSS
- **State Management:** React Context API
- **Deployment:** Vercel
- **System Design:** Role-based full-stack architecture

---

## ⚙️ Challenges Faced

- Implementing secure authentication and route protection
- Managing role-based access (admin vs user flow)
- Integrating CMS data with dashboard UI
- Handling complex state management across components
- Designing a clean and usable admin interface under hackathon pressure
